# 院内ローカルLLM セットアップガイド
**作成日**: 2026-02-28
**作成者**: sudoK（K病院 内科・外科医）

---

## 1. ゴール

> **AmiVoice（院内導入済み）＋ ローカルLLM → 電子カルテ記載の半自動化**

病院のDMZ（院内ネットワーク）内に完結するシステムを構築し、
音声で話した内容をSOAP形式に整形して電子カルテへ貼り付けできる状態を目指す。

クラウドAI（ChatGPT・AquaVoice等）は院内ネットワーク制約上使用不可。
**完全オンプレミス**で実現することが必須条件。

---

## 2. 現状の課題

| 課題 | 詳細 |
|:-----|:-----|
| AquaVoice導入不可 | セキュリティ・ネットワーク制約 |
| AmiVoiceは導入済み | 音声→テキスト変換は使える |
| 電カルは富士通製 | 直接API連携は困難 |
| スタッフのAI習熟度が低い | AIを使っているのは2〜3人程度 |
| 提案先は事務長（管理部） | 理事長より現実的な意思決定者 |

---

## 3. システム構成（目標）

```
医師が音声で話す
    ↓
AmiVoice（院内導入済み・医療辞書あり）
    ↓ テキスト出力
ローカルLLM（DMZ内 Mac mini）
    ↓ SOAP形式に整形
整形済みテキストを画面表示
    ↓ 手動コピー
富士通 電子カルテに貼り付け
```

| | Mac mini i3 / 32GB | M1 Mac / 16GB |
|:|:--|:--|

| 使用可能モデル | 7Bまで快適 | 7B快適・13Bも可 |
| 本番向き | △ POC向き | ○ 実用向き |

## 6. セットアップ手順

### ① モデルのダウンロード

```bash
# ターミナルで実行（約2.5GB、Wi-Fi環境で）
ollama pull gemma3:4b

# 動作確認
ollama run gemma3:4b
# >>> が出たら成功。/bye で終了
```

### ② Pythonスクリプト作成

`test_llm.py` として保存：

```python
import requests

def format_medical_note(raw_text):
    prompt = f"""以下の音声テキストを、内容を一切変えずにSOAP形式に整形してください。
推測・補足・解釈は絶対にしないでください。

音声テキスト：
{raw_text}

S（主訴）：
O（客観所見）：
A（評価）：
P（計画）："""

    response = requests.post(
        "http://localhost:11434/api/generate",
        json={
            "model": "gemma3:4b",
            "prompt": prompt,
            "stream": False
        }
    )
    return response.json()["response"]

# テスト実行
sample = """
患者70歳男性 主訴は血圧高め めまいあり 既往は高血圧糖尿病
今日の血圧168の92 脈拍78 体重64キロ 前回より2キロ増加
下腿浮腫軽度あり 呼吸音清 心音整 腹部異常なし
HbA1c7.8 空腹時血糖142 アムロジピン増量 次回2週間後採血
"""

print(format_medical_note(sample))
```

```bash
# 実行
python3 test_llm.py
```

## 8. LLMの役割と注意点

**LLMは「整形専用」として使う。医学的判断はさせない。**

| LLMが得意 | LLMが苦手（させない） |
|:----------|:---------------------|
| SOAP形式への並べ替え | 珍しい疾患名の漢字変換 |
| 箇条書き・整形 | 文脈からの推論・補足 |
| 定型句の整理 | 略語の文脈解釈 |

> ⚠️ 生成されたテキストは**必ず担当者が目視確認**してから電カルへ貼り付ける
