# 医療特化プロンプト集

**対象モデル**：gemma3:4b / qwen2.5:3b（Ollama）
**用途**：電子カルテ記載支援

---

## 基本ルール（全プロンプト共通）

```
- 内容を一切変えず整形のみ行う
- 推測・補足・解釈は絶対にしない
- 存在しない所見を追加しない
- 出力後は必ず医療者が目視確認する
```

---

## Python実行スクリプト（コピペで動く）

```python
import requests

def ask_llm(prompt):
    response = requests.post(
        "http://localhost:11434/api/generate",
        json={
            "model": "gemma3:4b",
            "prompt": prompt,
            "stream": False
        }
    )
    return response.json()["response"]

def format_soap(raw_text):
    prompt = f"""以下の音声テキストを、内容を一切変えずにSOAP形式に整形してください。
推測・補足・解釈は絶対にしないでください。

音声テキスト：
{raw_text}

S（主訴）：
O（客観所見）：
A（評価）：
P（計画）："""
    return ask_llm(prompt)

# 使い方
raw = "ここに音声認識テキストを入れる"
print(format_soap(raw))
```
